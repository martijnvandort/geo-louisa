# Geo Louisa

Welcome to Louisa's World of knowledge, culture and fun.

Pick a region or a country, choose what to find, and play the map quiz in English or Dutch.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

The app starts at http://127.0.0.1:43123. Leave the values in `.env.local` blank to play solo on the free basemap.
